# Alex media branding

Repo-native SVG artwork made for this site. The warm gradient, folded linework and thin rounded lowercase lettering reference the Zune-era visual language. The monogram combines A, F and R; the wordmark reads “alex”. The lettering is drawn as paths, so it doesn't depend on an installed font or claim to bundle the proprietary Zune font.

The Alex Messenger icon in `../xp/alex-messenger.svg` is an original two-person blue/green vector illustration inspired by the MSN Messenger era.

The wordmark was revised on 2026-10-20 to thin straight-stroke uppercase ALEX with square caps and sharp joins; the AFR symbol is retained.
